# Новости из Instagram → раздел «Новости» на сайте

Бот раз в несколько часов смотрит посты в Instagram, переписывает подпись в новость
на четырёх языках сайта, забирает фото из поста и добавляет запись в `lib/news.ts`.

- `@nsart_kz` — публикуется сразу (коммит в `main`, дальше Vercel сам выкатывает сайт).
- `@nur_kali` — не публикуется сразу: бот готовит ветку и Pull Request, решение за человеком.

## Что нужно один раз настроить

### 1. Аккаунты в Instagram

Оба аккаунта должны быть **профессиональными** (Business или Creator) — у личных аккаунтов
доступа к API нет. Переключение: Instagram → Настройки → Тип аккаунта → «Переключиться на
профессиональный». Внешне профиль не меняется, подписчики остаются.

Facebook-страница при этом **не нужна**: мы используем «Instagram API with Instagram Login».

### 2. Приложение в Meta (15 минут, один раз)

1. https://developers.facebook.com → «Мои приложения» → «Создать приложение» → тип **Business**.
2. В приложении: «Добавить продукт» → **Instagram** → «API setup with Instagram login».
3. Там же: «Business login settings» → в поле **Redirect URI** вписать
   `https://nsartgateway.com/` (точный адрес не важен, он нужен только чтобы забрать код).
4. Внизу страницы «Generate token» для каждого аккаунта: нажимаете, входите под
   `nsart_kz`, подтверждаете доступ — получаете **долгоживущий токен (60 дней)**.
   Повторяете для `nur_kali`.
5. Скопировать значения и выдать боту (следующий шаг).

Нужное разрешение одно: `instagram_business_basic` (чтение своих постов). Публиковать
что-либо в Instagram бот не умеет и прав на это не просит.

### 3. Секреты в GitHub

Репозиторий → Settings → Secrets and variables → Actions → New repository secret:

| Имя | Что это |
|---|---|
| `IG_TOKEN_NSART` | токен аккаунта `@nsart_kz` |
| `IG_TOKEN_CEO` | токен аккаунта `@nur_kali` |
| `GEMINI_API_KEY` | бесплатный ключ Gemini (из `~/.secrets/newGemeniFreeKey.txt`) |
| `TG_BOT_TOKEN` | (необязательно) бот для уведомлений |
| `TG_CHAT_ID` | (необязательно) куда слать уведомления |

Токен живёт 60 дней и продлевается автоматически при каждом запуске бота. Если бот
не запускался больше 60 дней, токен придётся выпустить заново тем же способом.

## Как запускается

- Автоматически: `.github/workflows/news-bot.yml`, каждые 3 часа.
- Вручную: вкладка Actions → «Новости из Instagram» → Run workflow.
- Локально:

```bash
IG_TOKEN_NSART=... GEMINI_API_KEY=... node tools/news-bot/bot.mjs --dry
```

`--dry` — ничего не записывает, только показывает, что бот сделал бы.
`--since=2026-05-20` — забрать посты начиная с даты (для разового «догона» пропущенного).

## Что бот не делает сам

- Не выдумывает факты: в новость идёт только то, что есть в подписи поста.
  Если подпись короче 180 символов — пост пропускается как «не новость».
- Не трогает уже опубликованные новости.
- Не публикует посты с личной страницы без ревью человека.
